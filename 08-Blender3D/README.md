# 08 — Blender 3D

Папка для исходных 3D-сцен проекта квартиры в формате Blender (`.blend`).

## Совместимость
- Целевая версия: **Blender 3.0.1**.
- Сцены сохранять в формате `.blend`, совместимом с Blender 3.0.1.
- Для каждой рабочей даты создавать отдельную подпапку `YYYY-MM-DD`.
- Не перезаписывать предыдущие дневные версии: сохранять новые итерации отдельными файлами.

## Структура дневной папки
- `01-scenes/` — основные файлы `.blend`.
- `02-assets/` — вспомогательные модели, текстуры и материалы.
- `03-exports/` — экспортированные модели и изображения из Blender.

См. текущую дату в подпапке `2026-11-11/`.
