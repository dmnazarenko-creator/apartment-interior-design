# Test scene — Blender 3.0.1

`generate_test_scene_blender_3_0_1.py` creates a simple 5.2 × 4.2 m living-room blockout with floor, walls, window, radiator, sofa, media console, camera and lighting. Open the script in Blender 3.0.1 and run it from the Scripting workspace. It saves `apartment-test.blend` next to the script.

**Important:** the repository currently contains the generator script, not a prebuilt `.blend` binary. The preparation environment did not have Blender installed and could not download the official Blender 3.0.1 binary. The actual `.blend` is created when this script is run inside Blender 3.0.1.

Six sample interior images are stored in the ChatGPT Library under `/Apartment Interior/08-Blender3D/2026-11-11/02-assets/`.
