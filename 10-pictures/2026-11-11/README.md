# Архив визуализаций — 2026-11-11

Папка для сохранения всех графических материалов, созданных в рамках дизайн-проекта квартиры за эту дату.

## Разделы
- `01-sketches/` — предварительные наброски и идеи.
- `02-drafts/` — промежуточные варианты планировки и расстановки мебели.
- `03-renders/` — итоговые 3D-визуализации помещений.

## Правила архива
- Исходные изображения сохраняются без перезаписи.
- Для новых итераций и новых дней создаются отдельные файлы и папки.
- В именах файлов указываются помещение, вариант и дата, например: `kids-room-layout-v01-2026-11-11.png`.
