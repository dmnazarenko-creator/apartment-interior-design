# Дизайн-проект квартиры

Рабочий репозиторий проекта: планировочные решения, мебель, интерьерная концепция, 3D-модели и визуализации.

## Исходные данные
- Состав семьи: 2 взрослых и подросток (13–18 лет).
- Стиль: современный минимализм.
- Бюджет: средний.
- Спальня взрослых: предусмотреть гардеробную зону.
- Стены, электрика, освещение и сантехника уже выполнены — проектируем мебель и отделочно-декоративное наполнение без переноса существующих инженерных точек.
- Подоконники: ориентировочно 900–1000 мм от чистого пола; под окнами установлены радиаторы. Не размещать высокие шкафы перед окнами и не перекрывать конвекцию радиаторов.

## Принципы проектирования
1. Сохранить доступ к окнам, радиаторам, дверям и инженерным узлам.
2. Предусмотреть технологические зазоры и доступ для обслуживания радиаторов.
3. Проверять габариты мебели по фактическим обмерам после черновых работ.
4. Для подростковой комнаты предусмотреть полноценное спальное место, рабочую зону, хранение и гибкое освещение.
5. В спальне взрослых организовать компактную гардеробную зону.
6. Для прихожей и кухни использовать встроенное хранение там, где оно не конфликтует с проходами и существующими коммуникациями.

## Статус
Подготовлена структура проекта и зафиксированы исходные требования. Чертежи по детской и прихожей/кухне представлены в переписке; перед выпуском точных мебельных чертежей нужны исходные файлы/обмеры в масштабе и проверка размеров на объекте.

## Важное ограничение
Изображения чертежей, присланные в чате, пока не скопированы в репозиторий как исходные файлы. Добавить их можно после загрузки самих файлов (PDF/JPG/PNG/DWG).
